# ⚛️ Atomic — AI Study & Educational Games

> **Created with ❤️ by Aarav, Vaibhav, and Aarnav from NPS Class 7B**

**Atomic** is a next-generation gamified learning and AI study platform. It combines personalized AI tutoring, interactive arcade mini-games, spaced-repetition flashcards, and neural mastery analytics into a sleek **Interstellar Monochrome** aesthetic.

---

## 🌟 Key Features

1. **Equation Quest (RPG Math Battles)**:
   - Rapid-fire algebraic equations and arithmetic against cosmic monsters.
   - Combo streaks, dynamic damage scaling, special abilities, and boss battles.

2. **Vocabulary Void (Black Hole Word Gravity)**:
   - Space-themed spelling and vocabulary builder.
   - Catch cosmic letter meteorites before they collapse into the event horizon.

3. **History Hero (Interactive Time Travel)**:
   - Make critical historical decisions across Apollo 11, Renaissance Florence, and Ancient Egypt.
   - Real-time Timeline Stability and Knowledge Score tracking.

4. **24/7 AI Tutors**:
   - Multiple specialized AI personas (Physics, Algebra, Computer Science, World History).
   - Powered by the modern Gemini AI SDK.

5. **Flashcard Magic & Spaced Repetition**:
   - 3D flip study flashcards with rating algorithms.

6. **Progress Analytics**:
   - Mastery gauges, study streaks, and subject score tracking.

## 🚀 Quick Start Guide

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open your browser at `http://localhost:3000`.

### 3. Build for Production
```bash
npm run build
```
